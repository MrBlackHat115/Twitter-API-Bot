# Twitter-API-Bot

A Python-based Twitter/X bot project built while learning how to work with APIs and automation using Python and Tweepy.

This project explores how Python can interact with the Twitter/X API to retrieve account information, process followers, search tweets, and perform automated actions.

> ⚠️ **Note:** This project was created as a learning exercise. Twitter/X API access, endpoints, permissions, and pricing may change over time, so some functionality from the course may no longer work with the current API.

---

## 📚 What I Learned

Through this project, I practiced:

- Working with APIs
- API authentication
- Using the Tweepy Python library
- Using OAuth authentication
- Working with API cursors
- Iterating through API results
- Handling API rate limits
- Using `try` / `except` for error handling
- Automating repetitive tasks with Python
- Searching API data
- Performing actions based on API results
